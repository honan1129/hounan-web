## 公開までの手順（3ステップ）

### ステップ1　GitHubにアップロード

1. GitHub で新しいリポジトリを作る（例：`hounan-web` ／ **Public**）
2. 「Add file → Upload files」で、このフォルダの中身を**まるごと**アップロード
   - `index.html` などのHTMLファイル
   - `assets` フォルダ、`img` フォルダ
   - `CNAME`、`robots.txt`、`sitemap.xml`、`404.html`
   - `CNAME` ファイルは必ず入れてください（独自ドメインの設定に必要です）
3. 「Commit changes」を押す

### ステップ2　GitHub Pages を有効にする

1. リポジトリの **Settings → Pages**
2. Source を `Deploy from a branch` ／ Branch を `main` ・ `/ (root)` にして **Save**
3. 数分待つと `https://ユーザー名.github.io/hounan-web/` が開きます
4. 同じ Pages の画面の **Custom domain** に `hounan-yakiniku.com` と入力して Save
   - `CNAME` ファイルを入れてあるので、すでに入力済みになっているはずです
5. DNSの設定（ステップ3）が反映されると **Enforce HTTPS** にチェックが入れられるようになります。
   必ずチェックを入れてください（鍵マークが付きます）

### ステップ3　ドメイン側のDNS設定

ドメインを取得した会社（お名前.com等）の管理画面で、`hounan-yakiniku.com` の
DNSレコードに以下を登録します。

**Aレコード（ホスト名は空欄または「@」）— 4つとも登録**

```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

**AAAAレコード（ホスト名は空欄または「@」）— 4つとも登録**

```
2606:50c0:8000::153
2606:50c0:8001::153
2606:50c0:8002::153
2606:50c0:8003::153
```

**CNAMEレコード（www を使えるようにする）**

```
ホスト名：www
値：      ユーザー名.github.io
```

※ AAAAレコードは省略しても表示されます（IPv6対応用）。Aレコード4つは必須です。

DNSが行き渡るまで**数十分〜最大48時間**かかります。しばらく開けなくても
設定ミスとは限りません。半日待ってから確認してください。

## まだ入れていない写真（任意）

`img/` に入れて、HTMLの該当箇所を差し替えます。

差し替え前：
```html
<div class="ph wide">写真6／コースの肉盛り<br>img/course.jpg</div>
```
差し替え後：
```html
<img src="img/course.jpg" alt="豊南焼肉のコースの肉盛り">
```

| ファイル名 | 使う場所 | 優先度 |
|---|---|---|
| `parking.jpg` | 宴会・アクセス | 高（大型車が停まっている絵があると団体客に効く） |
| `course.jpg` | お品書き | 中 |
| `lunch.jpg` | お品書き | 中 |
| `store.jpg` | みかわ牛 | 低 |
| `ogp.jpg` | SNS共有用（1200×630px） | 低（現在はトップの肉写真を使用） |

写真は横1600px程度に縮めてからアップすると表示が速くなります。
